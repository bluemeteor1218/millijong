# ミリオン麻雀

## 起動

ユニット管理で `data.js` を更新する場合は、GitHub Pagesなどの静的配信ではなく、プロジェクトフォルダーでローカルサーバーを起動してください。Python 3.10以上が必要です。

```powershell
py server.py
```

起動時に2つの異なる管理パスワードを入力します。入力文字は画面に表示されません。各パスワードは12文字以上にしてください。パスワードをソースコードやGitへ保存しないでください。

サーバー起動後、`http://127.0.0.1:8765/` を開きます。認証セッションはメモリー上で30分有効です。ユニット追加は認証済みのセッションだけに許可され、追加内容はこのフォルダーの `data.js` に保存されます。追加後は通常どおりGitへコミット・pushすると公開データにも反映できます。

この実装は `127.0.0.1` からの管理に限定しています。インターネットやLANへ直接公開しないでください。複数端末から管理するには、許可するHTTPSオリジンを限定したサーバー構成が別途必要です。GitHub Pages単体では、公開ページからリポジトリ内の `data.js` を安全に書き換えられません。

## テスト

```powershell
py -m unittest test_server -v
```
